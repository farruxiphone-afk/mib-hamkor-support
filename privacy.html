Какие данные используются

Учетные данные для входа и идентификатор пользователя; предоставленные сведения профиля, имя, телефон, район и паспортные сведения; выбранные фотографии и документы; обращения, сообщения по обращениям, результаты и сведения о расчетах. Документы могут содержать личные и финансовые сведения. Отправляйте только необходимые для вашего обращения материалы, которые вы вправе передавать.

Если вы отмечаете объект на карте, его координаты могут сохраняться в обращении. Доступ к текущему местоположению, камере и выбранным фотографиям используется с разрешения устройства для соответствующей функции. Фоновое отслеживание местоположения не предусмотрено.

Зачем и кому доступны данные

Данные нужны для входа, передачи и обработки документов, связи исполнителя с уполномоченными сотрудниками, отображения статуса и результатов обращения, расчетов и защиты сервиса. Данные обращения доступны его участникам и уполномоченным сотрудникам обслуживающей организации; приложение не публикует их в открытой ленте.

При выборе маршрута координаты передаются выбранному вами картографическому приложению. Карта использует OpenStreetMap: при загрузке карты ее поставщик получает обычные сетевые сведения, включая IP-адрес и запросы картографических фрагментов. К сторонним картам применяются их собственные политики.

Хранение и защита

Обращения и файлы хранятся на серверах сервиса и в резервных копиях. На устройстве может храниться локальная копия для работы приложения; приватное хранилище текущей версии шифруется. Передача к API выполняется по HTTPS. Технические журналы используются для безопасности и устранения неполадок. Рекламного отслеживания, продажи персональных данных и рекламных SDK в приложении нет.

Регистрация и Telegram

В приложении можно подать заявку на регистрацию, указав имя, телефон, организацию, логин и, для МИБ, район. Перед отправкой требуется согласие на обработку этих сведений. Заявка передается через Telegram-бот @evro_pro_uz_bot только администратору сервиса для проверки доступа. Telegram обрабатывает содержимое такого сообщения по собственной политике. Пароль в Telegram не отправляется; сервер хранит его защищенный хеш. До одобрения доступен только ознакомительный режим без работы с реальными документами.

Удаление аккаунта в приложении

До одобрения используйте кнопку удаления аккаунта в демонстрационном режиме. После одобрения откройте профиль и выберите удаление аккаунта, подтвердив логин и пароль. Личный профиль удаляется либо обезличивается, активные сеансы отзываются. Для заявки на регистрацию удаляются персональные сведения; сервер ставит запрос на удаление или обезличивание сообщения заявки у администратора Telegram. Рабочие документы, созданные для организации, остаются в ее архиве, как и сведения других участников внутри этих документов; это не удаление всего дела. Для исправления или удаления данных непосредственно в документах обратитесь к разработчику. Удаление приложения само по себе не удаляет серверный аккаунт. Резервные копии обновляются по своему циклу.

Разрешения и изменения

Разрешения камеры, фотографий и геолокации можно изменить в настройках устройства. Без них соответствующие дополнительные функции могут быть недоступны. При изменении обработки данных эта страница будет обновлена. Вопросы по данным и работе приложения направляйте в поддержку.
